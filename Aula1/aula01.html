Este é um parágrafo. Vamos demonstrar neste exemplo diferentes tags de HTML5, para analisar como funcionam.

Esta é uma tag div. Ela é um bloco retangular onde podemos colocar texto, figuras etc. Dentro vamos colocar esta tag span, de tipo inline que não quebra linha e não é tag de tipo bloco.

Esta é uma tab section, é uma tag de bloco, introduzida no HTML5, considerada uma "tag semnântica", como também as tags article, section, header, footer, figure...
Esta é uma tag article. Dentro vamos colocar algo em negrito, outro texto em itálico, outro texto sublinhado e um texto marcado.
